## 日本語

**アプリ名**（30 文字以内）

```
1億円 〜1万円札を1万枚めくれ〜
```

**簡単な説明**（80 文字以内）

```
1万円札を1万枚めくって1億円を数えきれ！ タップ連打でタイムを競う、シンプルで熱いタイムアタック
```

**詳しい説明**

```
目の前に積まれた、1万円札1万枚。
1枚ずつめくって、1億円を数えきるまでのタイムを競おう。

ルールはかんたん。お札をタップすると1枚めくれる。それだけ。
最初の1枚をめくった瞬間にタイマーがスタートし、10,000枚めくり終えたらゴールです。

■ 1億円を数える快感
・タップするたびにお札が宙を舞う
・100枚（100万円）ごとに帯封が1束埋まり、「ガシャーン」とお札を数える機械の音
・1,000万円ごとに「突破！」の演出
・金額・枚数・タイム・速度（枚/秒）をリアルタイムで表示

■ 記録に挑戦
・自己ベストを自動で保存
・タイムに応じた称号：「堅実な会計係」から「伝説の札勘マスター」まで
・結果を友だちにシェア

■ 金のお札
・広告を見ると、次の1回を金色に輝くお札で遊べる（見た目だけで、タイムには影響しません）

■ その他
・別のアプリに切り替えると自動で一時停止（タイマーも止まります）
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

あなたは1億円を何分で数えきれるか。指が限界を迎える前に、ゴールまでめくりきれ！

※ 画面上のお札は見本です。
```

## Play Console「アプリのコンテンツ」の回答の目安

- **プライバシー ポリシー**: https://techgym.jp/privacy-policy/
- **広告**: 「はい、広告を含みます」（バナー・インタースティシャル・リワード）
- **アプリのアクセス権**: 「制限なし（ログイン不要）」
- **ターゲット ユーザー**: 13 歳以上（13 歳未満を含めると広告に制限がかかる）
- **データ セーフティ**: アプリ自体は個人情報を集めないが、Google AdMob が「デバイスまたはその他の ID（広告 ID）」と「アプリの操作（広告の表示・クリック）」を広告とアナリティクスの目的で収集・共有する。通信は暗号化されている。※ AdMob の公式ガイドに従って最終確認すること
- **広告 ID**: 「使用する」（目的は「広告またはマーケティング」と「アナリティクス」）
- **コンテンツのレーティング**: ゲーム → 暴力・性的表現・言葉づかい・ギャンブル（実際のお金を賭ける要素、ギャンブルの模擬）はいずれも「いいえ」。お金を数えるだけで、賭けや購入の要素はない
