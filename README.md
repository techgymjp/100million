# 1億円

1万円札を1万枚めくって、1億円を数えきるまでのタイムを競うWEBゲームです。

## 遊び方

- `index.html` をブラウザで開き、「スタート」を押す
- お札をタップ / クリック、または `Space` `Enter` `F` `J` キーで1枚めくる
- 最初の1枚をめくった瞬間にタイマーがスタートし、10,000枚（1億円）めくり終えた時点でゴール
- キーの押しっぱなし（オートリピート）は無効
- `Esc` でタイトルに戻る
- 自己ベストはブラウザ（localStorage）に保存されます

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面構成 |
| `style.css` | スタイル・めくりアニメーション |
| `game.js` | ゲームロジック（タイマー、カウント、効果音、記録保存） |
| `images/10000yen.jpg` | 1万円札の画像 |

ビルド不要の静的サイトなので、GitHub Pages などにそのまま配置できます。

※ お札の画像（`images/10000yen.jpg`）には「見本」の文字を焼き込んでいます。
